## 日本語

### TOHFについて

TOHFは、[TownOfHost-K](https://github.com/KYMario/TownOfHost-K/)に役職・機能などを追加したModです。

このModを使用して発生したバグは、Innersloth様（Among Us公式）や他Mod様には報告せず、[TOHFの開発者](https://github.com/ToritenKabosu/TownOfHost-Fun/wiki/開発者)に報告してください。

詳細については、[Wiki](https://github.com/ToritenKabosu/TownOfHost-Fun/wiki/)をご確認ください。

### 禁止・注意事項

<details open>
<summary><b>禁止事項</b></summary>

- **公開部屋から、Mod部屋への誘導行為は厳禁です**
  - 例：非公開ルームでMod部屋を立て、公開部屋にてMod部屋のコードを貼り他ユーザーをMod部屋に誘導する行為 など

</details>

<details open>
<summary><b>注意事項</b></summary>

- **このMODはTOH-Kの派生MODであり、派生元のTOH-Kとは一切関係ありません。**
- このModはβ版です。予期しないバグが発生する可能性がありますので、ご理解のうえご利用ください。

</details>

## English

### About TOHF

TOHF is a mod that adds new roles and features on top of [TownOfHost-K](https://github.com/KYMario/TownOfHost-K/).

If you encounter any bugs while using this mod, please do **not** report them to Innersloth (the official Among Us team) or other mod authors. Instead, report them to the [TOHF developers](https://github.com/ToritenKabosu/TownOfHost-Fun/wiki/開発者).

For more details, please refer to the [Wiki](https://github.com/ToritenKabosu/TownOfHost-Fun/wiki/).

### Rules & Notes

<details open>
<summary><b>Prohibited Actions</b></summary>

- **It is strictly forbidden to recruit players from public rooms into mod rooms.**
  - Example: Creating a private mod room, then posting the room code in public lobbies to lure other users in.

</details>

<details open>
<summary><b>Notes</b></summary>

- **This MOD is a derivative of TOH-K and is in no way affiliated with the original TOH-K.**
- This mod is in beta. Unexpected bugs may occur — please use it with that understanding.

</details>

### Download

- **Latest:** https://github.com/ToritenKabosu/TownOfHost-Fun/releases/latest/
- **Older versions:** https://github.com/ToritenKabosu/TownOfHost-Fun/releases/

## 中文

### 关于TOHF

TOHF 是一个在 [TownOfHost-K](https://github.com/KYMario/TownOfHost-K/) 基础上新增职位和功能的 Mod。

如果在使用本 Mod 时遇到任何问题，请**不要**向 Innersloth（Among Us 官方）或其他 Mod 作者反馈，而应向 [TOHF 开发者](https://github.com/ToritenKabosu/TownOfHost-Fun/wiki/開発者) 报告。

更多详情请参阅 [Wiki](https://github.com/ToritenKabosu/TownOfHost-Fun/wiki/)。

### 禁止事项与注意事项

<details open>
<summary><b>禁止事项</b></summary>

- **严禁从公开房间诱导玩家进入 Mod 房间。**
  - 例：在私密房间创建 Mod 房间，然后在公开房间发布房间代码，将其他玩家引导进入 Mod 房间。

</details>

<details open>
<summary><b>注意事项</b></summary>

- **本 MOD 是 TOH-K 的衍生 MOD，与原版 TOH-K 没有任何关联。**
- 本 Mod 目前为 β 版，可能出现意料之外的错误，请在充分了解的前提下使用。

</details>
